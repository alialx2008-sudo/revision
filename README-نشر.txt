نشر منصات المراجعة برابط يحمل اسم المدرسة (مجاني – GitHub Pages)
==================================================================
1) أنشئ حسابًا على github.com باسم يحمل اسم المدرسة، مثل: gems-westminster-rak
2) أنشئ مستودعًا جديدًا (Public) باسم: revisions
3) اضغط Add file ← Upload files، وارفع كل محتويات هذا المجلد كما هي:
   index.html  و data.js  ومجلد img  ومجلد pdf
4) من Settings ← Pages اختر: Branch = main ، Folder = / (root) ثم Save
5) بعد دقيقة يصبح الرابط:  https://gems-westminster-rak.github.io/revisions/
6) زر «رمز المشاركة» داخل المنصة ينشئ رمز QR للرابط الجديد تلقائيًا.

لإضافة مراجعات جديدة لاحقًا: أرسل ملفات Word إلى Claude، فيُحدّث data.js ومجلد pdf، ثم ارفعهما مكان القديمين.
بديل: يمكن لقسم تقنية المعلومات رفع المجلد نفسه على موقع المدرسة (أي استضافة ملفات ثابتة).
